# ChatGPT

Two routes. Do both, because they reach different users.

## 1. ChatGPT app (MCP, Apps SDK)
- Server URL: `https://freelanceshield.me/api/mcp`, authentication: **None**.
- Test: ChatGPT → Settings → Apps & Connectors → Advanced → Developer mode → Create → paste the URL.
- Submit to the ChatGPT apps directory when submissions are open for your account. All tools are annotated `readOnlyHint: true`.

## 2. Custom GPT (GPT Store), no code
1. ChatGPT → Explore GPTs → Create → Configure.
2. Name: **FreelanceShield: Invoices, Contracts & Getting Paid**.
3. Instructions: paste `instructions.md`.
4. Actions → Create new action → Import from URL: `https://freelanceshield.me/openapi.json`. Authentication: None. Privacy policy: `https://freelanceshield.me/legal/privacy`.
5. Conversation starters:
   - "Make an invoice for 20 hours of design at ₹2,500/hr with 18% GST"
   - "My client is 12 days late on INV-014 for $1,800. Write a reminder."
   - "Check this contract before I sign it: …"
   - "Plan a ₹1,50,000 website project with fair milestones"
6. Publish → **Everyone**, category Productivity.
